Lists

Ordered List

  1. Use an ol tag
  2. Then use li to list the item
  3. Last make sure to include all closing tags
  4. Everything in an ordered list has a number

Unordered list

  • This is an unordered list
  • Its written almost the same as an ordered list
  • The difference is that it starts with ul
  • And instead of numbers it has bulleted points

Start with <ol> or <ul> with <li> nested inside for every item you list

Image Tag

You put in an image using img with src and the name of the image.
The name of this image is called grandcanyon.jpg
The only extensions that can be used with images is .jpeg, .png, and .jpg

Example: <img src="grandcanyon.jpg">

To change the width and height you use:
<img src="grandcanyon.jpg" width="200px" height="100px">
