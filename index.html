Adding a video

Find the video you are looking for on YouTube
Click Share
Then click Embed
Then paste the code into your program

Baby Shark

This is what the code looks like

Div Tags

This is used to divide the webpage into multiple sections. You can use style tags to create a box of any size or color, and you can have the text in whatever style

Here's the code I used to style this section:

<div style="background-color: blueviolet; color: aliceblue; height: 200px; text-align: center;"> TEXT GOES HERE </div>

Span Tags

Span is used to change the size, color or any property of text without starting a new paragraph

Here is the example of the code I used:

Span is used to <span style="font-size: 50px;">change the size, </span>
<span style="color: red;" >color</span> or any
<span style="color: blue;">property of text </span>
